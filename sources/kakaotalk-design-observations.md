# 카카오톡 디자인 관찰 기록 (25.7.3)

> 공개 배포된 카카오톡 Android 앱 25.7.3(빌드 28250730)의 컴파일된 리소스를 디코딩해서 **관찰한 수치와 패턴**을 정리한 기록입니다.
> 원본 리소스 파일, 이미지, 아이콘, 폰트, 코드는 포함하지 않습니다. 이 문서의 값은 학습과 참고를 위한 관찰 결과이며, 카카오의 공식 디자인 가이드가 아닙니다.
>
> 표기: `dp`/`sp`는 Android 단위이고, 웹에서는 `px`로 1:1 대응해 보면 됩니다.

## 0. 관찰 범위와 방법

- `base.apk`의 `res/values*`(colors, dimens, styles, attrs)를 `apktool`로 디코딩했습니다.
- 코드에서만 정의되는 버튼 크기는 버튼 위젯 클래스 두 개(`TdRoundButton`, `TdSquareButton`)에서 숫자만 확인했습니다.
- 사내 디자인 시스템 이름은 **TalkDesign**(리소스 접두사 `td_`, 스타일 접두사 `TalkDesign.`)으로 보입니다.
- 결제, 광고, 동영상, 게임처럼 별도 모듈(`pay_`, `fit_`, `adfit_`, `ktv_`, `games_` 등)은 제외했습니다. 각자 자체 토큰을 갖고 있어 메인 시스템과 섞이지 않습니다.

## 1. 색상 토큰 구조

### 1-1. 세 겹의 모드 레이어

| 레이어 | 의미 | 예 |
|---|---|---|
| `dayonly_*` | 라이트 모드 원본 값 | `dayonly_gray900s = #191919` |
| `nightonly_*` | 다크 모드 원본 값 | `nightonly_gray900s = #F2F2F2` |
| `daynight_*` | 화면이 실제로 참조하는 값. 기본은 dayonly를, `values-night`에서는 nightonly를 가리킴 | `daynight_gray900s` |

모든 TalkDesign 컴포넌트에는 `colorMode` 속성(`daynight` / `dayonly` / `nightonly`)이 있고, 스타일도 `.DayOnly`, `.NightOnly` 변형이 짝으로 존재합니다. 즉 **기본은 시스템 모드를 따르되, 특정 영역은 모드를 고정할 수 있는 탈출구**를 시스템 차원에서 제공합니다. 사진 뷰어나 미디어 편집처럼 항상 어두운 화면, 브랜드 노랑 위 영역처럼 항상 밝아야 하는 곳에 씁니다.

### 1-2. 이름 규칙: `{색}{명도}{s|a}`

- 숫자는 **명도 순서**입니다. 라이트 모드에서 숫자가 클수록 진해집니다.
- `s`(solid)는 불투명 색, `a`(alpha)는 투명도로 깔리는 오버레이입니다.
- 다크 모드에서는 **이름은 같고 값이 반전**됩니다. `gray900s`는 항상 "가장 진한 본문 글자"라는 역할을 유지합니다.

- 다크 배경도 순수 검정이 아니라 **#080808**입니다.
- 다크 모드의 `white001s~003s`는 점점 밝아집니다. **다크에서는 그림자 대신 명도로 높이(elevation)를 표현**합니다.

### 1-4. Gray (alpha)

| 토큰 | Day (검정 위 투명도) | Night (흰색 위 투명도) | 주된 역할 |
|---|---|---|---|
| gray000a | 3% | 6% | 아주 약한 면 |
| gray050a | 4% | 8% | 셀 눌림, ripple |
| gray070a | 6% | 10% | 회색 버튼 면, 입력창 |
| gray100a | 8% | 12% | |
| gray120a | 10% | 14% | |
| gray150a | 12% | 16% | 셀 테두리, 구분선 |
| gray200a | 14% | 22% | |
| gray300a | 20% | 35% | 선 버튼 테두리 |

- 구분선, 눌림, 회색 버튼 면처럼 **배경 위에 얹히는 것은 alpha 토큰**을 씁니다. 그래서 채팅방 배경색이나 사진 배경이 바뀌어도 그대로 어울립니다.
- 다크 모드의 alpha는 같은 이름이어도 **더 진합니다**(12% → 16%). 어두운 배경에서는 같은 투명도가 덜 보이기 때문입니다.

| 토큰 | Day | Night | 쓰임 |
|---|---|---|---|
| yellow500s | #FEE500 | #FEE500 | 브랜드. 주요 CTA, 전송 버튼, 안 읽은 수, 스낵바 액션, 스위치 켜짐 |
| yellow550s | #FBDD0D | #FBDD0D | 노랑 눌림 |
| blue300s | #ABC1D1 | #080808 | 기본 채팅방 배경 |
| blue500s | #0A73DC | #49A8F8 | 링크, 다이얼로그 버튼, 텍스트 선택 하이라이트(32% 투명) |
| red500s | #F4551E | #FF7849 | 삭제, 경고, NEW 배지, LIVE |
| red120a / red300a | 10% / 30% | 14% / 40% | 빨강 면, 빨강 선 |
| green500s | #00CD3C | #00CD3C | 성공, 포커스 힌트 |
| green600s | #05AC36 | #33B85A | 초록 눌림 |

- **노랑은 다크 모드에서도 값이 그대로**입니다. 브랜드 인지가 모드보다 우선합니다.
- 노랑 위 글자와 아이콘은 언제나 **#191919**입니다. 흰 글자를 올리지 않습니다.
- 빨강과 파랑은 다크 모드에서 **더 밝고 따뜻한 쪽으로 이동**해서 대비를 유지합니다.
- 다이얼로그의 텍스트 버튼은 노랑이 아니라 **파랑**입니다. 노랑은 면(fill)으로만 씁니다.

| 역할 | 연결 |
|---|---|
| title / header | gray900s |
| paragraph | gray500s |
| description | gray550s |

## 2. 타이포그래피

- UI 글꼴은 **시스템 기본 산세리프**입니다. 자체 브랜드 서체를 UI 전반에 깔지 않고, 숫자용 Roboto Medium 하나만 따로 둡니다.
- 버튼의 `letterSpacing`은 0으로 명시합니다. Material 기본 자간을 지워 한글이 벌어져 보이지 않게 합니다.
- 앱바 텍스트는 `includeFontPadding=false`로 글꼴 여백을 걷어 수직 정렬을 맞춥니다.

### 크기 스케일 (font_level)

`11 · 12 · 13 · 16 · 17 · 20 · 21 · 22 · 24 · 28 · 30 · 31 · 42` sp

### 역할별 크기

| 역할 | 크기 |
|---|---|
| 메인 탭 제목 (친구, 채팅 등) | 21sp |
| 앱바 제목 | 17sp |
| 캘린더 헤더 | 17sp bold |
| 바텀시트 헤더 | 16sp |
| 앱바 액션 텍스트 | 15sp |
| 목록 이름 | 15sp |
| 바텀시트 제목 | 15sp |
| 칩 (Large/Medium), 말풍선 본문 | 14sp |
| 칩 (Small) | 13sp |
| 섹션 제목, 날짜, 캡션 | 12sp |
| 보조 라벨 | 11sp |

굵기 차이보다 **크기와 색(gray900 / 600 / 550 / 500)으로 위계를 만듭니다.** bold는 헤더처럼 꼭 필요한 곳에만 씁니다.

## 3. 간격과 크기

### 간격

- `padding_*` 토큰이 1~27dp까지 **1dp 단위로 거의 다 존재**합니다. 4/8 그리드를 엄격히 강제하지 않고, 11.5dp, 16.5dp, 17.5dp 같은 반 단위 값도 씁니다. 텍스트 기준선을 눈으로 맞춘 흔적입니다.
- 자주 반복되는 값: 화면 좌우 여백 **16**, 목록 아이콘과 텍스트 사이 **12**, 다이얼로그 안쪽 **24**, 다이얼로그 바깥 **40**, 기본 간격 **8**.
- 구분선은 **0.5dp**(목록) 또는 **1px**(리스트 뷰)입니다. 두꺼운 선을 쓰지 않습니다.

### 높이

| 요소 | 값 |
|---|---|
| 앱바 | 56 |
| 팝업 메뉴 항목 | 48 (팝업 폭 160~250, elevation 4) |
| 채팅 목록 항목 | 68 |
| 목록 프로필(스퀴클) | 40, 상하 여백 8 |
| 바텀시트 핸들 영역 / 헤더 | 20 / 44 |
| 바텀시트 높이 | short 224 · normal 408 · peek 528 |
| 다이얼로그 피커 스피너 | 144 |

## 4. 컴포넌트

### 4-1. Round 버튼 (알약형, 내용 너비)

| 크기 | 최소 높이 | 글자 | 좌우 / 상하 패딩 | 아이콘 간격 |
|---|---|---|---|---|
| XLarge | 36 | 14 | 13 / 5 | 5 |
| Large (기본) | 32 | 13 | 12 / 4 | 5 |
| Medium | 30 | 12 | 12 / 3.5 | 5 |
| Small | 28 | 12 | 12 / 3 | 3 |
| XSmall | 25 | 11 | 10 / 2 | 3 |

색: `Yellow`, `Gray`, `GrayLine`, `White`, `WhiteLine`. 선 두께는 회색 선 0.5dp, 흰 선 1dp입니다.
쓰임: 카드 안의 보조 액션, 인라인 액션처럼 **화면의 주인공이 아닌 행동**.

### 4-2. Square 버튼 (꽉 찬 너비)

| 크기 | 최소 높이 | 글자 | 좌우 / 상하 패딩 | 모서리 |
|---|---|---|---|---|
| Large | 48 | 15 | 20 / 6 | 6 |
| Medium | 38 | 14 | 18 / 3 | 6 |
| Small | 32 | 13 | 12 / 1 | 5 |
| XSmall | 28 | 12 | 9 / 1 | 5 |

색: `Yellow`, `Gray`, `Line`, `SolidWhite`, `Red`, `RedAlpha`, `RedLine`. Small에는 아이콘만 있는 40×32 변형이 있습니다.
쓰임: 하단 확인, 시트의 주요 행동처럼 **화면의 결론이 되는 행동**. 위험한 행동은 Red 계열 3단계(면, 연한 면, 선)로 강도를 조절합니다.

### 4-3. Text 버튼

`Black` / `Gray` × `Large` / `Medium` / `Small` × 밑줄 여부. 밑줄은 링크성 행동(약관, 도움말)에만 붙입니다.

### 4-4. Chip

- 종류: `Tab`(필터 탭), `Option`(선택지), `Curation`(추천 키워드).
- 크기: Large·Medium 14sp, Small 13sp. 숫자를 붙이는 `.Number` 변형이 따로 있습니다.
- **선택 상태는 노랑이 아니라 반전**으로 표시합니다. Day: #222222 면 + 흰 글자 / Night: #F2F2F2 면 + #222222 글자.

### 4-6. 다이얼로그, 팝업, 스낵바

- 다이얼로그: 화면 좌우 40, 위아래 90 여백, 안쪽 좌우 24, 버튼 상하 8. 버튼 글자는 `blue500s`.
- 팝업 메뉴: 항목 48, 폭 160~250, elevation 4.
- 스낵바: 반전된 어두운 면(Day) 위에 밝은 글자와 노랑 액션. Night에서는 밝은 면과 어두운 글자로 다시 반전됩니다.

### 4-7. 프로필 모양

프로필 이미지는 원이 아니라 **스퀴클(squircle)**입니다. 스퀴클 테두리 색과 두께, 마스크 색을 별도 속성으로 둡니다.

## 5. 접근성 흔적

- `thma11y_` 접두사의 별도 색 세트가 있습니다. 접근성 테마(고대비)용으로 보입니다.
- 노랑 버튼 전용 접근성 ripple(`td_button_yellow_a11y_ripple`, 검정 16%)이 따로 있습니다. 노랑 위에서는 기본 ripple이 잘 안 보이기 때문입니다.
- 글자 크기는 `sp` 단위로 시스템 글꼴 크기 설정을 따릅니다. 단, 화면을 깨뜨리면 안 되는 곳에는 `font_*_dp`처럼 고정 크기 짝을 따로 둡니다.
